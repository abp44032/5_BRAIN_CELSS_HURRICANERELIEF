# 5 Brain Cells Hurricane Relief System
The Hurricane Relief System is an object-oriented hurricane relief platform that connects users such as victims, volunteers, and administrators to make disaster relief easier. Using facade and singleton design patterns, the system takes in and delegates aid requests appropriately, tracks shelter availability, and manages current emergency and hurricane updates.
